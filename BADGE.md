# Super Admin Platform

This repository is the **Super Admin Platform** — the platform control plane
(`platform-api` backend + `super-admin` frontend), sharing TypeBox API contracts
with a tenant `admin` frontend.

It began from an internal Fastify + React + Prisma starter; that lineage is
historical only and does not define this project's identity. See
[`README.md`](./README.md) and [`docs/CONVERSION-INVENTORY.md`](./docs/CONVERSION-INVENTORY.md).
